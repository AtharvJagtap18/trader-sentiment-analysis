# Trader Performance vs Market Sentiment Analysis

## Objective
Analyze how Bitcoin market sentiment (Fear/Greed) affects trader behavior and performance on Hyperliquid.

## Methodology
- Cleaned and aligned datasets by date
- Created daily PnL per account
- Calculated win rate and trade frequency
- Segmented traders:
  - High vs Low frequency
  - Consistent vs Inconsistent
- Compared performance across sentiment categories

## Key Insights
1. Extreme Greed days show highest average PnL.
2. High-frequency traders perform better in Greed periods.
3. Low-frequency traders perform better during Fear periods.

## Strategy Ideas
1. Increase trade frequency during Extreme Greed.
2. Reduce exposure during Extreme Fear unless trader has strong consistency.

## How to Run
Open analysis.ipynb and run all cells.
